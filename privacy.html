Политика конфиденциальности

Настоящая политика описывает, какие данные могут быть получены при использовании сервиса Remembera.

1. Какие данные мы получаем

При отправке формы пользователь может предоставить:

  • адрес электронной почты;
  • имя человека, которому посвящён знак памяти;
  • страну и город;
  • название кладбища;
  • номер могилы или участка;
  • текст личного послания.

2. Для чего используются данные

Данные используются только для обработки запроса, создания цифрового мемориального знака и связи с пользователем.

3. Передача третьим лицам

Мы не продаём персональные данные пользователей третьим лицам.

Для работы формы могут использоваться сторонние технические сервисы, необходимые для отправки данных.

4. Электронная почта

Электронный адрес пользователя используется для подтверждения запроса и связанных с ним сообщений.

5. Изменения

Настоящая политика может обновляться по мере развития сервиса.
