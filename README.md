# Remembera

Remembera — одностраничный сайт для создания символических цифровых знаков памяти в форме виртуальных цветов.

## Файлы

- `index.html` — главная страница
- `style.css` — дизайн
- `script.js` — интерактивность и отправка формы
- `privacy.html` — политика конфиденциальности
- `terms.html` — условия использования

## Запуск

Сайт не требует сервера.

Можно открыть `index.html` локально или разместить проект через GitHub Pages.

## Formspree

Для отправки заявок необходимо создать форму на Formspree.

После этого заменить в `index.html`:
